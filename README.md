# 共享转盘（Shared Spinner Wheel）

一个**网页版实时共享转盘**：苹果风灰金视觉、支持多个命名转盘各自选看、自定义选项（文字 / 颜色 / 权重 / 金色图标）。把链接发给朋友，进同一个房间，谁转动、转到什么，所有人**实时看到同一段动画和同一个结果**，并有"谁在哪个转盘转到了什么"的历史记录。手机 / 电脑自适应。

**零配置、纯前端**：不需要注册任何账号、不需要填写任何密钥、不需要后端服务器。实时同步由 [PeerJS](https://peerjs.com) 的公共信令（P2P）承担，前端托管在 **GitHub Pages**。

---

## 功能
- 多命名转盘：建多个转盘、改名、删除，每个人自己选当前看哪个
- 实时同步：转盘内容、转动结果、在线好友、历史记录都在同房间内实时共享
- 自定义选项：文字、颜色、权重（概率）、内置一套金色线性图标
- 苹果风灰金视觉 + 协调多彩扇区，选中块金色描边高亮
- 移动端自适应：手机上编辑面板收进底部抽屉，图标选择为底部弹层

## 部署（只靠 GitHub，约 3 分钟，无需任何账号配置）

### 1. 推送代码到 GitHub
代码已经在仓库里。在你自己电脑的终端进入项目目录，推一次即可：
```bash
cd spinner-wheel
git push
```
> 首次推送若提示要登录，用你的 GitHub 个人访问令牌（PAT）作密码；推完无需其他操作。

### 2. GitHub Pages 已开启
仓库的 Pages 已启用（Source = **GitHub Actions**）。之后每次推送 `main` 都会自动重新部署 `public/`，站点地址：
```
https://louisawang0212-source.github.io/spinner-wheel/
```

### 3. 和朋友一起玩
把下面这样的链接发给他们（`room=` 后面就是房间号，同一个号就是同一个房间）：
```
https://louisawang0212-source.github.io/spinner-wheel/?room=PARTY01
```
手机浏览器直接打开即可，无需安装。

- **发链接**：页面右上角点「分享」自动复制带房间号的完整链接，微信里直接粘贴。
- **报房间号也行**：点右上角的房间号（手机上显示为「加入 XXXXXX」），输入朋友的 6 位房间号即可跳进同一个房间。
- **换昵称**：顶栏「昵称」框改一下，其他人马上能看到。

> 小提示：同一房间里，**第一个打开链接的人**会临时充当"主机"来维持房间（他的浏览器保持房间状态）；他关掉页面房间就解散（本来就是临时房间）。想长时间挂着，让一个人一直开着那个标签页即可。

## 工作原理（纯前端，无中心服务器）
- 同一房间第一个打开的人 = **主机（hub）**，其余人作为客户端连接该主机；主机负责中转广播与在线状态。
- **P2P 实时同步**：转盘列表 / 选项 / 转动事件都通过 PeerJS 数据通道在房间内同步。
- **在线好友**：主机维护参与者列表（昵称、正在看哪个转盘），实时广播给所有人。
- **发起者权威**：谁点"转动"，谁本地按权重随机算出中奖扇区下标，再把同一个目标广播给全员，所有人用同一时长 / 缓动播放动画，保证落点完全一致。
- **状态自举**：新成员加入时向房间请求快照；若无人回应（你是第一个），则自动创建默认转盘。状态缓存在浏览器 localStorage，刷新 / 重连后恢复视图。
- **自动容错**：主机离开时，剩余成员自动重新选举出新主机，房间继续可用。

### 注意事项
- 这是"临时房间"设计：状态保存在各人浏览器 + P2P 通道中，没有数据库持久化，房间长期无人后会自然消失。
- PeerJS 公共信令是免费共享服务，个人小圈子玩耍完全够用；如需更高稳定性可自托管 PeerJS 服务（见下方）。
